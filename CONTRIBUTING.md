# Contributing to latch-lang projects

This is the default for every repository in the latch-lang organisation that has no `CONTRIBUTING.md` of its own;
the `latch` repository's own file has the details.

- **No outside contribution is merged until a contributor licence agreement (CLA) is in force.** Pull requests from
  outside the project are closed without review; open an issue instead. When the CLA is in force, this file will say
  how to sign it.
- **Security issues never go in public issues:** follow `SECURITY.md` (private vulnerability reporting, or email
  latchlanguage@gmail.com with a subject starting `[security]`).
- **AI assistance is disclosed:** a commit an AI tool helped write carries a `Co-Authored-By:` trailer naming the
  model. AI review never counts as independent review.
- Be courteous and specific; assume good faith.
