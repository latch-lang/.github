# Security policy

latch is pre-release. If you believe you have found a security issue in latch, its website or its published artifacts, please report it privately:

- **Email:** latchlanguage@gmail.com — subject line starting with `[security]`
- Please do not open public issues for security reports.

We aim to acknowledge reports within 5 working days. Once a release is published this policy will gain supported-version and disclosure-timeline details.
